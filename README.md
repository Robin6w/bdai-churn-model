# BDA 학습자 수료 예측 모델

BDA 학회 학습자의 **사전 설문 응답으로 수료 여부를 예측**하는 이진 분류 프로젝트입니다.
DACON [BDA 학습자 수료 예측 AI 경진대회](https://dacon.io/competitions/official/236664/overview/evaluation)에 참가하며 만든 코드입니다.

- 타깃: `completed` (1 = 수료, 0 = 미수료)
- 평가 지표: Binary F1 Score
- 최종 모델: CatBoost + LightGBM 가중 앙상블 → [`최종/0221_0.43864.py`](최종/0221_0.43864.py)

> 폴더 이름은 "이탈모델"이지만 실제 예측 대상은 **수료 여부**입니다. 미수료가 곧 중도 탈퇴를 뜻하지는 않습니다.

## 데이터

| 구분 | 기수 | 인원 | 수료(1) |
|---|---|---|---|
| train.csv | 9기 | 748명 | 223명 (29.8%) |
| test.csv | 10기 | 814명 | 정답 없음 |

입력은 학교·전공·직무·수강 분반·희망 직무·관심 기업·자유서술 등 44개 설문 문항입니다.
**학회원 설문 응답이므로 데이터 파일과 제출 파일은 저장소에 포함하지 않았고, 노트북도 출력(데이터 미리보기)을 지운 상태로 올렸습니다.**

## 최종 모델 (`최종/0221_0.43864.py`)

### 1. 피처 처리 (`build_features`)

| 처리 | 대상 |
|---|---|
| 제외 | `ID`, 전원 결측 문항(`idea_contest`, `contest_award`), 거의 전부 결측(`class4`, `contest_participation`) |
| 코드형 숫자 → 범주 | `generation`, `school1` |
| 다중 선택 → 개수 + 상위 토큰 이진 피처 | `desired_certificate`, `major_field`, `desired_job` (빈도 20 이상, 최대 10개) |
| 다중 선택 → 개수만 | `expected_domain`, `desired_job_except_data`, `onedayclass_topic`, `interested_company`, `previous_class_8` |
| 자유서술 → 형태 요약 | `incumbents_lecture_scale_reason` (길이, 단어 수, 숫자·영문·특수문자 포함 여부, 빈 응답 여부) |
| 결측 처리 | 범주형 `__MISSING__`, 수치형 학습 중앙값 |

### 2. 모델과 검증

- **CatBoost**: 범주형을 직접 입력하고, 양성 클래스 가중치는 `음성 수 / 양성 수 × 계수`
- **LightGBM**: 범주형을 frequency·label encoding과 fold 내부 target encoding(smoothing 20)으로 변환
- 두 모델의 OOF 확률을 가중 평균하고, 가중치(0~1)와 임계값을 OOF F1이 최대가 되도록 탐색

검증은 두 단계로 진행합니다.

1. **탐색**: 6개 설정을 seed 2개(42, 202) × Stratified 5-Fold로 비교
2. **확대 재검증**: 상위 2개 설정을 seed 3개(42, 202, 777), 더 큰 반복 상한, 더 촘촘한 가중치·임계값 격자로 다시 학습

### 3. 결과

탐색 단계 (`0221_search_summary.csv`, 앙상블 OOF F1 순):

| 설정 | 변경 내용 | CB F1 | LGB F1 | 앙상블 F1 | CB 비중 |
|---|---|---|---|---|---|
| `cb_weight_0p8` | CatBoost 양성 가중치 × 0.8 | 0.4731 | 0.4724 | **0.4939** | 0.52 |
| `lgb_cons_missing` | LGB 보수적 설정 + 행 결측 수·비율 | 0.4712 | 0.4825 | 0.4904 | 0.26 |
| `baseline` | 기본 설정 | 0.4721 | 0.4724 | 0.4876 | 0.56 |
| `cb_weight_off` | CatBoost 클래스 가중치 끔 | 0.4669 | 0.4724 | 0.4848 | 0.26 |
| `lgb_cons_missing_rare` | 위 설정 + 희귀 범주(<5회) 통합 | 0.4760 | 0.4609 | 0.4838 | 0.92 |
| `lgb_conservative` | LGB leaves 48, 최소 leaf 30, L2 2 | 0.4721 | 0.4640 | 0.4793 | 0.82 |

확대 재검증 (`0221_full_summary.csv`):

| 설정 | CB F1 | LGB F1 | 앙상블 F1 | CB : LGB | OOF 임계값 |
|---|---|---|---|---|---|
| **`cb_weight_0p8_full` (최종)** | 0.4741 | 0.4675 | **0.4883** | 0.6 : 0.4 | 0.388 |
| `lgb_cons_missing_full` | 0.4718 | 0.4803 | 0.4860 | 0.32 : 0.68 | 0.276 |

최종 제출은 테스트 예측의 양성 비율을 68.059%로 맞추는 분위수 임계값(0.3766)을 써서 **814명 중 554명을 수료로 예측**했습니다.
파일 이름의 `0.43864`는 당시 제출 점수로 기록해 둔 값입니다(Public/Private 구분 기록은 없음).

참고로 학습 데이터에서 모두 수료(1)로 예측하면 F1은 0.4593입니다.

## 한계와 개선 방향

- **기수가 다름**: 학습은 9기, 테스트는 10기입니다. 무작위 K-Fold는 9기 내부 일반화만 재므로 다음 기수 성능과 다를 수 있습니다.
- **전공 표기 차이**: `major1_1`이 학습에서는 11개 대분류, 테스트에서는 288개 세부전공으로 적혀 있어 범주 매핑이 테스트에 잘 맞지 않습니다. 전공 표준화가 우선 개선 대상입니다.
- **낙관적 OOF**: 설정·가중치·임계값을 같은 OOF에서 고르므로 OOF F1은 실제보다 높게 나올 수 있습니다. nested CV나 별도 검증 세트가 필요합니다.
- **토큰 분리 오류**: 다중 선택 파싱이 선택지 안의 쉼표까지 나눕니다(예: `컴퓨터활용능력(1,2급)`).
- **변환 기준**: 상위 토큰과 label encoding을 학습+테스트를 합쳐 정의합니다(타깃 누수는 아님).
